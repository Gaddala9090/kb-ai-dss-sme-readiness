# KB-AI-DSS — Knowledge-Based AI Decision Support for SME Digital Transformation Readiness

Code, data and outputs for the short communication
**"A Knowledge-Based AI Decision Support System for Assessing Digital Transformation Readiness and Innovation Potential in Entrepreneurial SMEs"** (submitted to *Knowledge-Based Systems*).

KB-AI-DSS treats expert knowledge as a prior and lets data correct it:

1. **Fuzzy knowledge base** — 54 readable IF–THEN rules over six readiness dimensions
   (strategy, leadership, data infrastructure, digital skills, processes, innovation culture),
   organised as three capability modules and a top module. Inference uses Ruspini partitions,
   product t-norm and weighted-average defuzzification, so **readiness is provably non-decreasing
   in every indicator**.
2. **Knowledge-guided blend** — `p = w·p_K + (1−w)·p_D`, where `p_K` calibrates the rule base to the
   outcome, `p_D` is a random forest, and `w` is learned from the training data only
   (inner cross-validated log-loss).
3. **Explanation and recommendation** — rule trace, linguistic labels, SHAP attributions and a
   what-if ranking of dimensions and modules to improve first.

## Reproduce

```bash
pip install -r requirements.txt
python -m pytest -q          # 5 property tests
python run.py                # about 10 minutes on 2 CPU cores
python run.py --quick        # smoke test with fewer repeats
```

Use your own survey: `python run.py --data my_survey.csv` with the 18 indicator columns
(see `DIMENSIONS` in `kbdss.py`), `size_log`, `firm_age`, `sector_ict`, `sector_services`
and a binary `innovation_potential` column.

## Use the system on a firm

```python
from kbdss import KBAIDSS, FuzzyKnowledgeBase, recommend
model = KBAIDSS().fit(X_train, y_train)           # X: pandas DataFrame, y: 0/1
FuzzyKnowledgeBase().infer(firm)                  # dimension, capability and readiness scores
model.predict_proba(firm)[:, 1]                   # probability of high innovation potential
recommend(model, firm)                            # ranked improvement actions
```

## Results

Synthetic benchmark of 800 SMEs (seed 42). Full numbers in `results/metrics.json`.

**Full sample** — 10-fold stratified CV × 5 repeats (`results/table2_performance.csv`):

| Model | AUC | F1 |
| --- | --- | --- |
| Fuzzy knowledge base only | 0.806 | **0.681** |
| Logistic regression | 0.808 | 0.657 |
| Random forest | 0.815 | 0.665 |
| Gradient boosting | **0.819** | 0.656 |
| KB-AI-DSS (proposed) | 0.810 | 0.667 |

**Small samples** — test AUC on 240 held-out firms, 20 splits (`results/fig2_learning_curve.png`):

| Training firms | Knowledge base only | Random forest | Gradient boosting | KB-AI-DSS | learned w |
| --- | --- | --- | --- | --- | --- |
| 40 | **0.801** | 0.769 | 0.726 | 0.790 | 0.54 |
| 80 | **0.804** | 0.798 | 0.769 | 0.802 | 0.49 |
| 160 | 0.797 | 0.799 | 0.788 | **0.800** | 0.57 |
| 320 | 0.804 | **0.813** | 0.811 | 0.805 | 0.60 |
| 560 | 0.801 | 0.818 | **0.819** | 0.808 | 0.59 |

The rule base is the most reliable component when data are scarce; data-driven models overtake
it only at about 320 firms. The blend stays within 0.012 AUC of the best model at every size.

## Data note

`results/sme_dataset.csv` is a **synthetic benchmark** generated by `simulate_smes()` (seed 42).
Its generating process encodes stylised facts from the digital-transformation literature and was
written independently of the rule base, but it shares the same broad assumptions. Validation on
real SME survey data is the necessary next step; the code runs unchanged on such data.
